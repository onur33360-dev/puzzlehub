# PuzzleHub Google Play Release Guide

## Goal

Ship a stable, policy-compliant application.

Release quality is more important than release speed.

------------------------------------------------------------------------

## Release Order

1.  Internal testing
2.  Closed testing
3.  Fix feedback
4.  Production rollout

------------------------------------------------------------------------

## Before Upload

-   Release build
-   Version code updated
-   Version name updated
-   No debug code
-   No test ads
-   No console errors

------------------------------------------------------------------------

## Store Listing

Required:

-   App name
-   Short description
-   Full description
-   Icon
-   Feature graphic
-   Phone screenshots
-   Privacy Policy URL

------------------------------------------------------------------------

## Data Safety

Complete honestly.

Review:

-   Collected data
-   Shared data
-   Encryption
-   Account deletion

------------------------------------------------------------------------

## Monetization

Before production:

-   Google Play Billing
-   Production AdMob IDs
-   Subscription testing
-   Purchase restoration

------------------------------------------------------------------------

## Security

-   Play Integrity enabled
-   App signing verified
-   Secrets removed
-   HTTPS only

------------------------------------------------------------------------

## Testing

Validate on multiple Android versions.

Check:

-   Installation
-   Upgrade
-   Purchases
-   Ads
-   Performance
-   Crashes

------------------------------------------------------------------------

## After Release

Monitor:

-   Crash reports
-   ANRs
-   Reviews
-   Ratings
-   Retention

Release hotfixes quickly when necessary.

------------------------------------------------------------------------

## Golden Rule

Never publish because the deadline arrived.

Publish because the application is ready.
